# ПР11: разбор результатов

За шаг движения среда начисляет 1 и вычитает 0,15 за каждую единицу поперечного смещения. Остановка даёт только штраф за смещение. Финиш добавляет 8, сход с полосы вычитает 8.

На десяти проверочных seed движение прямо дало 6 финишей, 4 схода и средний return 7,04. Q-политика дала 10 финишей, 0 сходов и средний return 15,18. Во всех двадцати заездах эпизоды завершились до лимита. Return в оценке — сумма наград за эпизод.

Для seed 10202 обе политики стартуют из `(1, 8)`. При движении прямо смещение последовательно достигает 2, затем 3 и на последнем шаге 4. Робот сходит с полосы с return −2,10. Q-политика после первого шага выбирает `left`, затем `right` и `left`, удерживая смещение внутри полосы. Последний `left` приводит в `(0, 0)`, к финишу с return 15,10. Полные последовательности действий и наград сохранены в `evaluation.json`.

Результат относится к этой дискретной модели и десяти заданным seed. Для применения к роботу с непрерывным управлением понадобится заново выбрать представление состояния и действий и проверить политику с учётом инерции, ошибок датчиков и задержек.
